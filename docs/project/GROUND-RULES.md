# Ground rules

Working agreements for every agent in this project. One line per item.

## Do

- Ask the user decision questions one at a time as a pop-up, recommended option first. Fallback: one numbered question per message.
- Scope rule of thumb for new features: if a feature answers "is this worth the tokens right now?", it is part of rightsize. If it answers "what does the next session need to know?", it is part of whatsnext.
