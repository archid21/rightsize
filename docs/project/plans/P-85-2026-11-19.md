# Plan: P-85 — Measured compact savings

- **Agent:** claude-code
- **Time:** 2026-11-19
- **Status:** approved; built 2026-11-20 (after the replay on past transcripts: formula confirmed; 3 requests kept; manual and auto shown apart)

Goal: today a compact's saving is only a guess and never reaches Total saved (only keep-warm returns do: `warmSaved`, [register.tsx:5012](../../../plugins/rightsize/hooks/register.tsx)). Measure each compact's whole effect and count it. Handoff notes and new chats get no dollar saving: out of scope.

**Measured saving** = Σ over each later request in the same session of (tokens cut × the price that request really paid for them: cache read, or cache write after a cold return) − the compact's own cost. Counting stops at the first of: the uncompacted chat would have reached `autoCompactThreshold`, the next compact, the session's end. It is a running figure ("so far"), not final.

1. **Tests first** (new `compactsaved.test.ts`; `cost`, `warm`, `coldtip`, `limit`, `report` tests). Each must fail before step 2:
   - Tokens cut = context before − context after, read at the compact.
   - Each later request adds tokens cut × its own price: a warm request at the cache-read price, a cold one at the cache-write price.
   - Counting stops at the auto-compact point (before + growth since ≥ threshold), the next compact, or session end.
   - A compact with no later requests is a loss of its own cost. A new session never adds to an earlier compact.
   - A compact followed by a wrap-up or session end within 3 requests is marked `startedFresh`.
   - The compact's own cost comes from session usage before and after it. If that usage cannot be read, the line says `cost: unknown` and is not counted.
   - Report: Total saved includes the measured savings; a "Compacts" row shows count, saved so far, and how many started fresh; old logs without the kind still load.
   - `compactSaving` is the only estimate formula: idle, net, tip, limit and the gate call it, passing in the compacting model (own or Sonnet) and warm or cold.
2. **Probe** — check live whether Claude Code reports the compact's own usage. If it does not, use the session usage delta. Note the result in the ADR.
3. **One estimate formula** — `compactSaving(prices, tier, context, summary, opts)` in [cost.ts:832](../../../plugins/rightsize/hooks/cost.ts); route `idleCost`, `netSaving` ([warm.ts:19](../../../plugins/rightsize/hooks/warm.ts)), `tipSaving` ([coldtip.ts:19](../../../plugins/rightsize/hooks/coldtip.ts)), `limitSaving` (cost.ts:849) and `compactGate` ([warm.ts:594](../../../plugins/rightsize/hooks/warm.ts)) through it. Only the band's estimates before a compact use it.
4. **Log the compact** — new RunLine kind `compactSaved` (`source`: button, tip, limit, auto; `before`, `after`, `cost`, `saved`, `requests`, `startedFresh`) in [report.ts:40](../../../plugins/rightsize/hooks/report.ts). Written at the compact (from `replaceContext` / `detectCompact`, [register.tsx:3422](../../../plugins/rightsize/hooks/register.tsx), :3456); updated after each later request from its real usage until counting stops.
5. **Report** — count `saved` in `totals` and Total saved ([report.ts:304](../../../plugins/rightsize/hooks/report.ts), :1283); add Compacts rows, manual and auto apart; keep compact rebuilds as expected in CACHE REBUILDS (:1454). Note in the report: counted as if the chat went the same way; quality cost not priced. No new setting: measuring changes no decision.

7. **Docs** — ADR 0098 (+ row in `docs/decisions/README.md`); CHANGELOG line under "## 0.16.2 (unreleased)". No own run counts in public text.
